# Before you begin

- Set up your webhook receiver and prepare to [handle webhooks](../webhooks/index.md).
- Contact your account manager to obtain a configuration ID.
- [Create a profile](../business-applicant-profiles/index.md) for the Business Applicant whose website you want to verify.

## Configuration

When you request an account, your account manager provides you a configuration ID, prefixed usj_. Provide this ID every time you create a verification. It configures:

- The checks you want to include within the Website Verification
- The data you want to extract from the websites
