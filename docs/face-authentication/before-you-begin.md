# Before you begin

- Set up your webhook receiver and prepare to [handle webhooks](../webhooks/index.md).
- Contact your account manager to obtain a configuration ID. 
- The applicant must been approved through an identity verification or a face authentication that has not been yet anonymized. 

## Configuration

When you request an account, your account manager provides you with a configuration ID, prefixed with usj_. Provide this ID every time you create a verification. It configures the following elements of the solution:

- The service level agreement for receiving the result from Checkout.com
- Processing type:
    - Auto – Fully automated processing
    - Expert – Systematic human review
