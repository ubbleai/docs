# Face Authentication

The Face Authentication solution enables you to confirm a user is the same person whose identity you've successfully verified using the Identity Verification solution. 
This helps you decide whether to allow them to access your services.

The solution works as follows:
- Create a verification linked to the applicant's profile.
- Create an attempt and redirect the applicant.
- The applicant captures video of their face.
- Checkout.com checks if the applicant matches the person whose identity you've successfully verified.
- Verify webhook notifications and retrieve the verification to see the result.
