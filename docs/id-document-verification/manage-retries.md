# Manage retries

If the first attempt is unsuccessful and the verification status changes to `retry-required`, you can create a new attempt using other images.
You can use the Create an attempt endpoint. 

We recommend sharing guidance from the [response codes](../reference-info/response-codes.md) with the applicant to help them succeed in their next attempt. 

If the verification status changes to `declined`, you will need to create a new ID Document Verification if you want to allow the applicant to retry.
